# Laundry Booking Website

A modern, responsive web application for booking laundry services online.

## Features

- **15+ Laundry Services**: Choose from a wide range of services including Dry Cleaning, Wash & Fold, Shoe Cleaning, and more.
- **Cart Management**: Add or remove services from your cart easily.
- **Form Validation**: Client-side validation for booking and newsletter forms.
- **Email Integration**: Integrated with EmailJS for sending booking confirmations directly to the user.
- **Responsive Design**: Fully responsive layout that looks great on mobile, tablet, and desktop devices.
- **Interactive UI**: Smooth scrolling, hover animations, and transitions for an enhanced user experience.

## Setup Instructions

1. Clone or download the repository to your local machine.
2. Ensure all files (`index.html`, `style.css`, `script.js`, `img.png`) are in the same folder.
3. No build tools or backend servers are required, as it is a static frontend website using vanilla HTML, CSS, and JS.

## How to Run

1. Simply open the `index.html` file in any modern web browser (Google Chrome, Mozilla Firefox, Safari, Edge, etc.).
2. You can also use a local server for a better development experience:
   - If you have Python installed: `python -m http.server 8000`
   - If you have Node.js and `serve` installed: `npx serve`
   - Alternatively, use the "Live Server" extension in VS Code.

## Usage

- Browse the available services in the "Our Services" section.
- Click **Add Item ⊕** to add a service to your cart.
- View your total amount dynamically updated in the cart section.
- Fill out the booking form with your Name, Email, and Phone number.
- Click **Book now** to finalize your booking. You will receive an alert upon successful submission.
